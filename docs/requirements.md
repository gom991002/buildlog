# BuildLog 기획 (초기 메모, 참고용)

> **이 문서는 초기 기획 메모입니다.** 이후 공개 기록, 댓글, 좋아요, 신고 등이 추가되어 내용이 달라졌습니다. 최신 기준은 [PRD.md](PRD.md), [spec.md](spec.md), [plan.md](plan.md)를 따릅니다.

공부한 내용, 할 일, 오류 해결 과정을 한곳에 기록하고 나중에 다시 찾아보는 서비스.

## 정해진 것

| 항목 | 결정 | 근거 |
|---|---|---|
| 사용 장소 | 여러 기기(컴퓨터, 휴대폰)에서 사용 | 사용자 답변 |
| 사용자 | 여러 사람이 가입해서 사용 | 사용자 답변 |
| 기록 공개 범위 | 각자 자기 기록만 볼 수 있음 (비공개) | 추천 — 공부 메모와 오류 기록은 개인적인 내용이 많음 |
| 저장 방식 | 모든 사람의 기록을 하나의 데이터베이스에 저장하고, 기록마다 작성자를 표시해 구분 | 추천 — 가장 일반적이고 단순한 방식 |

## 기능 (첫 버전)

### 1. 회원
- 이메일과 비밀번호로 가입, 로그인, 로그아웃
- 비밀번호는 암호화해서 저장 (원래 비밀번호를 그대로 저장하지 않음)

### 2. 공부 기록
- 제목, 내용, 날짜(자동으로 오늘 날짜, 수정 가능)
- 최신 기록이 위에 오는 목록
- 기록 보기, 수정, 삭제
- 제목과 내용으로 검색

### 3. 할 일
- 할 일 내용 한 줄 (예: "저장 버튼 만들기", "파이썬 복습하기")
- 체크해서 완료 표시, 다시 체크하면 완료 취소
- 보기 전환: 전체 / 남은 일 / 끝난 일
- 수정, 삭제

### 4. 오류 기록
- 오류 제목(오류 메시지), 상황 설명, 상태(미해결 / 해결), 해결 방법
- 처음엔 해결 방법을 비워둔 채 "미해결"로 저장하고, 해결하면 해결 방법을 적고 "해결"로 변경
- 보기 전환: 전체 / 미해결 / 해결
- 오류 제목, 상황, 해결 방법으로 검색
- 수정, 삭제

## 화면과 디자인
- 화면 위쪽 메뉴: 공부 기록 / 할 일 / 오류 기록
- 휴대폰 화면에서도 쓰기 편하게 화면 크기에 맞춰 배치
- 장식은 최소화하고 글씨와 입력칸 위주로 단순하게
- 내용 입력은 일반 텍스트(줄바꿈 유지). 오류 메시지나 코드를 붙여 넣는 일이 많으니 고정폭 글꼴로 보여주는 방식은 만들 때 정함

## 만드는 방법 (확정, PRD 10장)
- 화면(frontend): React
- 서버(backend): Python + FastAPI
- 데이터베이스(database): 개발·테스트는 SQLite, 실제 서비스는 Supabase(PostgreSQL)
- 근거: 기존 `.gitignore`에 Python(`.venv`, `__pycache__`)과 Node(`node_modules`, `dist`) 항목이 이미 있고, 할 일 예시에 "파이썬 복습하기"가 있음

## 첫 버전에 넣지 않는 것
- 태그나 분류, 공부 기록과 오류 기록 연결
- 이미지나 파일 첨부
- 다른 사람과 기록 공유
- 비밀번호 찾기 (이메일 발송 기능이 필요해서 나중에)

## 미리 알아둘 점
- 여러 기기에서 쓰려면 서버를 인터넷에 올려야 함. 어디에 올릴지(호스팅)와 비용은 아직 정하지 않음
- 다른 사람의 이메일과 비밀번호를 받으면 개인정보를 다루게 되어 보안과 법적 책임(개인정보 보호 관련)이 생김. 공개 서비스로 열기 전에 확인 필요
